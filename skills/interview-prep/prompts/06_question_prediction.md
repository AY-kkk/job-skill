# Prompt 06: 面试问题预测

## 用途
结合候选人简历、岗位要求和竞品信息，预测面试官可能会问的问题。

## 输入变量
- `{{resume}}` — 候选人简历内容
- `{{job_analysis}}` — 岗位分析结果（来自Prompt 01）
- `{{product_info}}` — 目标产品信息
- `{{competitor_info}}` — 竞品分析结果（可选）

---

## Prompt 内容

你是一位面试准备顾问。请针对以下候选人和岗位，找出最值得优先准备的问题。问题是基于材料的准备建议，不代表真实面试官一定会问。

**候选人简历**：
```
{{resume}}
```

**岗位分析**：
```
{{job_analysis}}
```

**目标产品信息**：
```
{{product_info}}
```

**竞品信息**（可选）：
```
{{competitor_info}}
```

## 判断依据

综合考虑 JD 重要性、简历暴露度、证据缺口、目标产品和面试轮次。不要使用无依据的固定权重或概率。

## 输出要求

按类别分组。数量由岗位重点和准备时间决定，避免为凑数量生成泛题。

每个问题包含：
- 问题内容
- **考察点**：面试官想考察什么能力
- **证据来源**：JD 条目、简历片段、产品研究或信息缺口
- **追问方向**：基于材料可能继续核实什么
- **准备优先级**：高 / 中 / 低 + 判断依据
- **待补信息**：生成真实回答前还需候选人确认什么

### 第一类：简历深挖题（最高频）
从简历中找最亮眼/最可疑/和岗位最相关的项目，深入提问

### 第二类：岗位匹配度题
考察候选人是否具备岗位要求的核心能力，以及为什么适合这个岗位

### 第三类：产品/行业理解题
考察候选人对目标产品、竞品、行业趋势的理解深度

### 第四类：综合素质题
考察思维方式、价值观、职业规划等软实力

### 优先准备
单独列出最值得优先准备的问题，并解释选择依据；不要使用“必考”或确定性通过承诺。

不得增加简历中没有的经历、数字、客户、成果或个人贡献。
