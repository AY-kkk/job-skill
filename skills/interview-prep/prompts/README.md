# Prompt 模板库

本目录包含面试准备 Skill 各环节使用的 Prompt 模板。

---

## 模板清单

| 模板文件 | 用途 | 输入 | 输出 |
|----------|------|------|------|
| `01_job_analysis.md` | 岗位JD拆解 | 岗位描述 | 岗位考察重点 + 能力矩阵 |
| `02_product_extract.md` | 产品信息结构化提取 | 页面文本 + 产品名 | 统一格式的产品JSON |
| `03_competitor_discovery.md` | 竞品发现与筛选 | 目标公司 + 产品方向 | 竞品列表 + URL |
| `04_comparison.md` | 竞品横向对比分析 | 多个产品的结构化数据 | 对比表 + 差异分析 |
| `05_swot.md` | SWOT分析 | 目标产品 + 竞品对比 | SWOT矩阵 + 战略洞察 |
| `06_question_prediction.md` | 面试问题预测 | 简历 + 岗位要求 + 竞品分析 | 高频问题列表 + 分类 |

## 使用说明

### 基本用法

1. 选择对应的 Prompt 模板文件
2. 复制模板内容
3. 将模板中的 `{{占位符}}` 替换为实际内容
4. 发送给大模型获取结果

### 变量约定

所有模板中的占位符使用 `{{变量名}}` 格式：

| 变量 | 说明 |
|------|------|
| `{{company}}` | 目标公司名称 |
| `{{product}}` | 目标产品名称 |
| `{{job_description}}` | 岗位JD全文 |
| `{{resume}}` | 候选人简历内容 |
| `{{page_text}}` | 产品页面纯文本 |
| `{{products_json}}` | 多个产品的结构化JSON数据 |
| `{{question}}` | 具体面试问题 |

### 输出格式约定

- 结构化提取类：严格 JSON 格式（可被 json.loads 解析）
- 分析报告类：Markdown 格式
- 问答类：Markdown 列表格式，每个问题配回答

## 质量控制

### 提取类 Prompt 通用约束

所有信息提取类 Prompt 都必须包含以下约束：

1. **真实性**：只提取原文中明确提到的信息，不得编造
2. **可追溯**：关键信息尽量标注原文出处（关键词/句子）
3. **证据充分度**：标记 complete / partial / insufficient，并说明缺失字段
4. **完整性**：不确定或原文没有的字段填 `null`，不要留空或猜测

### 分析类 Prompt 通用约束

1. **有依据**：每个结论尽量有数据/事实支撑
2. **客观**：不贬低任何产品，保持中立分析
3. **有深度**：不只是罗列事实，要有洞察和判断
4. **结构化**：输出格式清晰，便于快速阅读

### 所有模板的证据约束

1. **内容分级**：区分“已验证事实”“基于证据的推断”“候选人观点”“待确认信息”
2. **来源时间**：公开信息保留来源 URL、页面标题和查询日期
3. **简历真实性**：不增加候选人未确认的经历、数字、客户、成绩或个人贡献
4. **缺失处理**：材料不足时输出澄清问题，不用模型记忆补齐当前事实
5. **预测边界**：问题和趋势是准备优先级或情景判断，不是确定性预测

## 迭代说明

Prompt 模板需要持续优化。如果发现某个模板效果不好，可以：

1. 记录 bad case（输入是什么、输出哪里不对）
2. 调整 Prompt（增加约束、补充示例、调整结构）
3. 在模板末尾的"版本记录"中更新
