# Prompt 03: 竞品发现与筛选

## 用途
根据目标公司和产品方向，找出主要竞品，并筛选出最值得深入调研的3-5家。

## 输入变量
- `{{company}}` — 目标公司名称
- `{{product_direction}}` — 产品方向（如"数据智能体""AI Agent平台"）
- `{{industry}}` — 行业范围（可选）
- `{{search_evidence}}` — 已通过搜索或浏览取得的候选公司、产品和来源
- `{{as_of_date}}` — 调研日期

---

## Prompt 内容

你是一位行业研究员。只基于提供的搜索证据整理候选对象；不要依赖模型记忆生成当前公司、产品或 URL。

我正在调研 **{{company}}** 的 **{{product_direction}}** 方向，需要你帮我找出主要的竞争对手。

**调研日期**：{{as_of_date}}

**搜索证据**：
```
{{search_evidence}}
```

请完成以下任务：

## 任务1：列出主要竞品
列出该赛道的主要玩家（10家以内），每家包含：
- 公司名称
- 核心产品名称
- 一句话定位
- 市场地位判断及依据；没有可靠依据时写“待确认”
- 已在搜索证据中确认的官网产品页 URL；不得猜测 URL

## 任务2：竞品分层
将竞品分为三个梯队：
- **第一梯队（直接竞品）**：产品定位、目标客户、核心功能高度重合的
- **第二梯队（间接竞品）**：有部分功能重叠，但定位或客户群有差异的
- **第三梯队（潜在竞品）**：目前不在同一赛道，但有能力切入的

## 任务3：推荐深入调研名单
推荐少量最值得深入调研的竞品，并说明推荐理由；数量由证据质量决定，不为凑数加入对象。

选择标准（综合考虑）：
1. 市场地位高、有代表性的
2. 和目标产品竞争最直接的
3. 产品特色鲜明、有差异化优势的
4. 与目标岗位的研究重点直接相关

## 任务4：关键信息搜索词
为每家推荐调研的竞品，给出3-5个最适合搜索的关键词，用于后续深度调研。

输出格式用 Markdown，结构清晰。每个对象标注“已验证事实 / 基于证据的推断 / 待确认信息”，并附来源 URL 与查询日期。
