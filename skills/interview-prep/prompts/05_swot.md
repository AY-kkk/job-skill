# Prompt 05: SWOT分析

## 用途
对目标产品进行SWOT分析，帮助候选人在面试中展现战略思考深度。

## 输入变量
- `{{product_name}}` — 目标产品名称
- `{{company}}` — 所属公司
- `{{comparison_report}}` — 竞品对比分析报告（来自Prompt 04的输出）
- `{{market_context}}` — 市场/行业背景信息（可选）

---

## Prompt 内容

你是一位科技行业战略分析师，擅长用SWOT框架做深度产品分析。

请基于以下信息，为 **{{company}}的{{product_name}}** 做一份SWOT分析：

**竞品对比信息**：
```
{{comparison_report}}
```

**市场背景**：
```
{{market_context}}
```

## 输出要求

### SWOT矩阵

| | 正面 | 负面 |
|---|------|------|
| **内部** | **S - 优势（Strengths）** | **W - 劣势（Weaknesses）** |
| | 列出5-8条内部优势 | 列出4-6条内部劣势 |
| **外部** | **O - 机会（Opportunities）** | **T - 威胁（Threats）** |
| | 列出4-6条外部机会 | 列出3-5条外部威胁 |

每一项同时标注：事实依据、来源、推断链和待确认信息。Strengths/Weaknesses 必须是内部能力证据，Opportunities/Threats 必须是外部环境证据。

### 深度分析

#### 1. 优势怎么放大？
- 哪些优势是护城河级别的？怎么巩固？
- 哪些优势可以转化为商业化增长点？

#### 2. 劣势怎么补？
- 哪些劣势证据充分、影响较大？优先级最高的补短板方向是什么？
- 哪些劣势可以通过合作/收购弥补？

#### 3. 机会怎么抓？
- 最大的机会窗口是什么？为什么？
- 怎么从现有能力延伸到新机会？

#### 4. 威胁怎么应对？
- 最大的威胁来自哪里？竞品/技术/政策？
- 应对策略是什么？

### 战略方向建议
基于SWOT分析，给出3条战略方向建议：
1. 进攻型策略（利用优势抓机会）
2. 防御型策略（弥补劣势抗威胁）
3. 差异化策略（建立独特竞争壁垒）

### 面试表达建议
面试中如果被问到"你怎么看这个产品的竞争格局/未来发展"，怎么表达比较好？
- 开口怎么说（30秒版本）
- 展开怎么说（2分钟版本）
- 哪些观点适合在什么面试阶段说

要求：
- 分析要有深度，不只是贴标签
- 每条S/W/O/T都要有具体的事实/数据支撑
- 战略建议要可落地，不是空话
- 面试表达建议要实用、可直接用
- 材料不支持的判断放入待确认清单，不补写公司内部信息
